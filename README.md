HOW TO USE

First, enter your name in the console.

Next, enter the two numbers you want to calculate when prompted with nhap a va b.

Select the operation you want to perform:

+ : Addition

- : Subtraction

* : Multiplication

/ : Division

% : Percentage calculation

^ : Exponentiation

s : Square root

| : Absolute value

Finally, when tiep tuc(y/n) appears, enter n to exit the loop or y to continue calculating.
